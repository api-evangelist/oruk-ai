Oruk AI provides speech understanding APIs that enable transcription and vocal delivery analysis for both recorded audio and live speech. Their platform supports multiple languages and offers various output formats tailored to developers integrating speech AI into applications such as voice assistants, call analytics, and content creation tools. The service emphasizes low latency, high accuracy models, and flexible pricing options for different usage scales.

**Areas:** Company · Speech · AI · Transcription · Voice

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Oruk: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
